# День 2 — ГИС-парсер

## Цель дня

Python-модуль на **GeoPandas** для чтения геоданных (GeoJSON/OSM)
и разделения карты на три слоя: **здания, дороги, существующие теплосети**.

## Файлы дня

### `backend/app/gis/parser.py`
Ядро дня — класс `GISParser`.

- **Чтение.** `load_layer()` читает `data/<слой>.geojson` через
  `geopandas.read_file`. Если у файла нет CRS — принимаем EPSG:4326.
  Всё переводится в метрическую CRS (по умолчанию UTM 37N): дальше
  1 единица = 1 метр, что критично для 3D-сцены.
- **Кэш.** Прочитанные слои кэшируются в `_cache`, повторные запросы
  не трогают диск.
- **Нормализация.** `_geom_coords()` превращает геометрии Shapely
  в простые списки координат `[x, y]` (без Z): полигоны — внешнее
  кольцо, линии — список точек. У зданий нормализуется атрибут
  `floors` (этажность, нужна на Дне 4).
- **Приведение к локальному нулю.** UTM-координаты — сотни тысяч
  метров; с такими числами в WebGL теряется точность float32.
  Поэтому `to_response()` вычитает из всех координат левый нижний
  угол охвата карты: карта начинается от `(0, 0)`. Реальный угол
  возвращается в поле `origin` — абсолютные координаты всегда
  восстановимы.
- **Охват.** `_bounds()` считает совокупный bbox всех слоёв —
  фронтенд центрирует по нему камеру.

### `backend/app/gis/osm_loader.py`
Загрузчик «сырых» данных OpenStreetMap (.osm, XML).

- GeoPandas/pyogrio читает OSM послойно (`points`, `lines`,
  `multilinestrings`, `multipolygons`) — функция `_read_osm()`
  склеивает всё в один GeoDataFrame.
- `osm_to_layers()` классифицирует объекты по OSM-тегам:
  `building=*` → здания (этажность из `building:levels`),
  `highway=*` → дороги, `substance=heat`/`pipeline=*`/`heat=*` → теплосети.
- Теги, которые pyogrio не вынес в колонки, разбираются из строки
  `other_tags` вида `"key"=>"value"` (`_tags()`).

### `backend/app/api/routes_map.py`
Роутер `GET /api/map/layers`. Отдаёт все слои одним запросом в формате,
готовом для фронтенда: `{crs, origin, bounds, layers: {...}}`.
Парсер приходит через `Depends(get_parser)` — см. `deps.py`.

### `backend/app/data/*.geojson`
Демо-набор: 11 зданий с этажностью 2–12, сетка из 9 улиц и 3 линии
теплосетей (магистраль + два ответвления) с диаметрами труб.
Координаты — условный квартал в EPSG:32637. Заменяется реальными
выгрузками (например, из OSM через `osm_loader.py`) без изменения кода.
