# День 3 — Базовая low-poly триангуляция

## Цель дня

Реализовать на бэкенде **алгоритм Делоне (SciPy)** и передавать
массив треугольников рельефа на фронтенд.

## Файлы дня

### `backend/app/terrain/triangulation.py`

- **`demo_height(x, y)`** — аналитическая функция высоты: два
  гауссовых холма разной высоты и ширины + слабая синусоидальная
  волнистость. Даёт наглядный рельеф без внешних данных. Когда
  появится реальная ЦМР (SRTM, лидарная съёмка), заменяется только
  источник точек — весь остальной конвейер не меняется.
- **`sample_terrain_points(size, grid)`** — сетка `grid × grid` точек
  с высотами. К узлам добавляется случайный джиттер (до 25% шага
  сетки, генератор с фиксированным seed=42):
  1. у правильной сетки четыре соседних узла лежат на одной
     окружности — вырожденный случай для Делоне;
  2. нерегулярный узор выглядит естественнее в low-poly стиле.
  Фиксированный seed гарантирует одинаковый рельеф между запусками.
- **`triangulate(points)`** — сама триангуляция:
  `scipy.spatial.Delaunay` строит триангуляцию проекции точек на
  плоскость XY (это стандартный подход для 2.5D-рельефа: высота —
  атрибут вершины, не участвующий в триангуляции). Возвращает два
  плоских массива — `vertices` (x,y,z подряд) и `faces` (тройки
  индексов вершин), плюс статистику и охват.
- **`terrain_mesh()`** — композиция «точки → триангуляция» для API.

### `backend/app/api/routes_terrain.py`

- **`GET /api/terrain/mesh`** — готовый меш демо-рельефа.
  На сетке 40×40: 1600 вершин, ~3180 треугольников.
- **`POST /api/terrain/triangulate`** — триангуляция произвольного
  облака точек от клиента (тело: `{"points": [[x,y,z], ...]}`).
  Задел на будущее: пользовательские отметки высот, реальная ЦМР.
  Валидация входа — через Pydantic-модель `PointsRequest`.

## Почему плоские массивы

JSON не имеет типизированных массивов, а фронтенду нужно заполнить
`Float32Array`. Плоский формат `[x0,y0,z0, x1,y1,z1, ...]` копируется
в GPU-буфер практически без обработки (см. День 4, `terrain.js`).

## Проверка дня

```
GET /api/terrain/mesh →
  point_count: 1600, triangle_count: ~3179,
  vertices: длина = 1600*3, faces: длина = triangle_count*3
```
