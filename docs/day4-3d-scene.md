# День 4 — Первое 3D-окно (фронтенд)

## Цель дня

Отрисовать в **Three.js** low-poly ландшафт и «выдавить» (extrusion)
здания по их этажности.

## Файлы дня

### `frontend/src/scene/MapScene.jsx`
Главный компонент сцены. Vanilla Three.js внутри React через
`useRef`/`useEffect` (без react-three-fiber — меньше зависимостей,
вся мощь three в чистом виде).

- **Инициализация (один раз):** сцена с тёмным фоном и туманом,
  перспективная камера, `WebGLRenderer`, `OrbitControls` (вращение/
  зум мышью), ambient + directional свет, вспомогательная сетка.
  Рендер-цикл на `requestAnimationFrame`, ресайз по событию окна.
  При размонтировании всё корректно освобождается.
- **Эффекты-надстройки:** отдельные `useEffect` для рельефа, слоёв
  карты, нового здания, подсветки теплосети и линии врезки. Каждый
  эффект удаляет старый объект сцены и добавляет новый — так React
  управляет Three.js декларативно.
- **Живые объекты** (scene, camera, sampler) хранятся в `stateRef`,
  чтобы эффекты видели друг друга без пересоздания сцены.

### `frontend/src/scene/terrain.js`
Сборка рельефа из ответа `/api/terrain/mesh`.

- **Смена осей.** Бэкенд считает Z «вверх» (ГИС-традиция), в Three.js
  «вверх» — Y. Конверсия: `(x, y, z) → (x, z, -y)`, минус у Y —
  чтобы север карты смотрел «от камеры».
- **BufferGeometry** из плоских массивов: `position` + `setIndex(faces)`,
  `computeVertexNormals()` для освещения.
- **Раскраска по высоте:** вершинные цвета от зелёного (низины) к
  серо-бурому (вершины) + `flatShading: true` — фирменный low-poly
  вид с видимыми гранями треугольников.
- **`makeHeightSampler()`** — драпировка: возвращает функцию высоты
  рельефа в любой точке карты (рейкаст вертикально вниз на меш).
  Без неё здания и линии «тонут» в холмах — рельеф местами выше
  30 метров, а линии рисовались бы на нулевой отметке.

### `frontend/src/scene/buildings.js`
Extrusion зданий.

- **`buildBuilding(feature)`** — контур полигона → `THREE.Shape` →
  `ExtrudeGeometry` с глубиной `floors × 3 м`. Поворот геометрии
  `rotateX(-90°)`: выдавливание идёт вверх (ось Y сцены).
  Цвет — от светлого (малоэтажка) к тёмно-коричневому (высотки).
- **`drapeOnTerrain()`** — опускает здание на рельеф: высота берётся
  сэмплером в центре контура, `mesh.position.y = высота`.
- **`buildNewBuilding()`** — то же, но полупрозрачный зелёный материал
  (перспективное здание Дня 5).
- **`buildMarker()`** — сфера-маркер над Точкой Б.

### `frontend/src/scene/networks.js`
Линейные слои.

- **Дороги** — серые `THREE.Line`.
- **Теплосети** — красные линии. Плюс к каждой — невидимый
  `TubeGeometry` радиусом 4 м вокруг линии: тонкую линию кликом
  не попасть, по трубе Raycaster попадает легко (задел Дня 5).
- Все вершины линий проходят через сэмплер высоты — линии «лежат»
  на рельефе с подъёмом 1.5 м.

## Проверка дня

Запущенные backend + frontend показывают: холмистый low-poly рельеф
с градиентом высоты, стоящие на нём здания разной высоты
(2–12 этажей), серую сетку дорог и красные линии теплосетей.
Камера вращается мышью (OrbitControls).
