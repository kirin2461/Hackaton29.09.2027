# Дельта техприложения — актуальная редакция ЛЦТ-2026

**Дата разбора:** 23.09.2026 · **Версия движка:** dit-lct2026.2-java
**Источники:** новое Техническое приложение (полная замена расчётной модели),
официальные «Разъяснения по вопросам ЛЦТ», облако организаторов
(официальный датасет `!!!_Датасет.geojson`).

Актуальная редакция — это **переписанное с нуля техприложение**, а не правки:
изменены схема входа/выхода, смета, скоринг, правила ДУ и глубины.
Ниже — что изменилось относительно первичной редакции и как это внедрено
(справочники/тарифы/правила — только в `reference.yaml`, §2.14 ТЗ).

## 10. Известные границы

- Отступы чужих ОКС и запреты проверяются по растру 3 м — погрешность
  до ячейки; собственный полигон освобождается точно (по геометрии).
- Совместное подключение — эвристика «кластер + ствол», не точный Штейнер.
- Совпадение точки подключения с местом присоединения (расстояние 0)
  оформляется участком нулевой длины — точка считается подключённой.
- В режиме глубины отметки коммуникаций — из `reference.yaml`
  (`existing_utilities`), а не из входных данных (в схеме §1 их нет).
